# Waterways in Wolfe County Kentucky

A line-based map showing waterways across Wolfe County Kentucky, created as part of the [30 Day Map Challenge](https://www.30daymapchallenge.com) to practice GIS skills.

## How to View

This project was built in QGIS and exported as a web map. Click the deployment link below to view it in your browser:

👉 [View the Map](https://kaliehyde.github.io/Waterways-in-Wolfe-County-Kentucky/)

## Tools

- [QGIS](https://qgis.org) (open-source desktop GIS)
- [30 Day Map Challenge](https://www.30daymapchallenge.com)
